RetroArchive is a catalog of software for the **Nokia N79** and other S60 3rd Edition phones. It lists apps and games for Symbian (.sis, PyS60) and Java ME (.jar and .jad), together with the SDKs and tools needed to install and build them.

## What is here

- **My Apps**: [RetroSend](/apps/retrosend/) (send files with the LocalSend app over Wi-Fi), [RetroTele](/apps/retrotele/) (a Telegram client that talks to Telegram directly) and [RetroTorch](/apps/retrotorch/) (a torch that uses the camera LED, the screen and the keypad light).
- **SDKs and tools**: the [Symbian S60v3 toolchain](/sdks/symbian-s60v3-toolchain/) for building native code on Linux, the [Python for S60 1.4.5](/sdks/pys60-runtime/) runtime, and the tools that the guides refer to.
- **Guides**: how to install Python for S60, how memory-card installs work, how to install Java apps, how to build native code on Linux, and how to unlock the N79 with EasyHackKit.

The archive will also list third-party software that has been tested on the N79. Each tested entry gives the device and the result.

## Downloads and licences

App files come from GitHub Releases. Third-party binaries are not stored in this site's repository. Nokia SDK archives are linked to their archive.org copies, because their licences do not allow re-hosting.
